# Suggested Code Availability statement

The Python implementation of DFAA-MemoryNet is publicly available through the
dedicated GitHub repository (https://github.com/imane-se/DFAA-MemoryNet). The repository contains the
model architecture, predictor-construction utilities, soil-moisture-memory
input utilities, training and normalization procedures, sliding-window
inference, evaluation metrics, and reusable LOYO/LOEO split routines. The
released code supports construction, training, evaluation, and application of
DFAA-MemoryNet once the required predictor fields have been prepared.
Study-specific data preprocessing, the DFAA event catalogue, manuscript
figures and tables, sensitivity analyses, trained weights, prediction caches,
and derived research products are not included in the software repository.
