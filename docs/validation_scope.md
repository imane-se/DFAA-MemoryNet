# Validation scope

`validation.py` provides reusable LOYO and LOEO split generators.

The construction of independent DFAA event identifiers, preconditioning
windows, recovery windows, and any manuscript-specific exclusion buffers is
dataset-specific and is not distributed in this model-only repository.

This separation keeps the public repository focused on the DFAA-MemoryNet
software rather than the complete analysis workflow of the associated study.
